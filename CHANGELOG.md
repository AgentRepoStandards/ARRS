# Release notes

## 0.1.0 — Experimental source release candidate

Prepared for public source release at [AgentRepoStandards/arrs](https://github.com/AgentRepoStandards/arrs). Install from a source checkout using the [README](README.md); npm publication is outside this release.

- Initialize a repository contract with command mappings, Feature Maps, architecture boundaries and risk policies while preserving existing files.
- Check versioned JSON contracts and supported JavaScript/TypeScript imports, and capture local Proof Contracts with freshness checks and bound review requirements.
- Prepare bounded tasks and inspect readiness, capability relationships, work state and selected proof. Optional local MCP tools provide read-only inspection.
- Install the pinned skill pack offline with retained upstream provenance and MIT attribution.

This is an early implementation with evolving interfaces. Real application pilots remain outstanding, and the opt-in Python adapter is provisional. Hosted CI execution and provider admission remain unqualified. ARRS does not sandbox repository commands, certify security or provide authenticated local reviewer identity. See the [current limits](README.md#current-limits) and [security policy](SECURITY.md).
