# Hosted CI toolchain

The four Ubuntu/Windows and Node 22/24 jobs provision Git 2.52.0 before running the existing gates. ARRS currently qualifies Git 2.52.x; runner image updates can install a different version, so the workflow does not use the image Git for those gates. The adapter's version admission and configured command argv/timeouts remain unchanged. Checkout runs first using the runner Git; source inspection and tests use the verified selected installation.

The unconditional `.github/scripts/setup-git.mjs` step uses Node's standard library and adds no npm dependency or third-party setup action. Its CI entry point accepts only fixed official artifacts, verifies SHA-256 before extraction or execution, installs under `RUNNER_TEMP`, checks the installed and PATH-selected versions, checks native remote-ext and shell availability, then writes `GITHUB_PATH` for later steps. Digest, extraction, command, feature or version failures stop setup before that path is published.

Ubuntu builds upstream Git v2.52.0 at immutable commit `9a2fb147f2c61d0cab52c883e7e26f5b7948e3ed`. Signed upstream tag `8273149fa7c8cbc30474b3d0028b62e2a474e152` resolves to that commit; GitHub reported its signature valid during preparation. The GitHub-generated source archive SHA-256 is `8b10342a49e19a02c2bcd32d77bde33d5ce88318b6d91c5dee5d7c85fcddb038`, independently downloaded during preparation. This is a locally recorded archive digest, not a separately signed publisher checksum. Ubuntu's configured signed package repositories supply `build-essential`, `libcurl4-openssl-dev`, `libexpat1-dev`, `gettext` and `zlib1g-dev`. Only optional Tcl/Tk GUI components are omitted. Evolving runner compilers and libraries mean this does not promise bit-for-bit identical Git binaries.

Windows expands the official immutable [Git-for-Windows v2.52.0.windows.1 release](https://github.com/git-for-windows/git/releases/tag/v2.52.0.windows.1) MinGit x64 ZIP. Publisher checksum and GitHub asset digest both give SHA-256 `f42a561840627747ad48e6ece05a14093292d31f3393a401a7f7c780ee7695c2`; a downloaded copy matched during preparation. MinGit supplies native Git, command helpers and a bundled shell for noninteractive use. It excludes GUI and optional tools without changing the adapter's native local Git commands. No administrative installer or registry change is used.

Provisioning is an executable CI control under R3 and its declared architecture module. It does not establish hosted matrix success or qualify later Git versions. Actual Ubuntu and Windows jobs remain necessary to establish platform behavior.
